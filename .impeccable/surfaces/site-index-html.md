# Open-source introduction

Mode: Persuade. Help an everyday PDF user understand Folio, download an
appropriate installer, and discover the project's source and contribution path.
The user asked for an adoption-focused GitHub Pages site and a real page review.

## Direction contract

THESIS: Your PDFs, your rules. Demonstrate a real document workspace, then
make the next action obvious; do not substitute invented popularity or parity.

OWN-WORLD: Preserve Folio's original folded-page mark, clear blue actions,
cool white paper and slate ink. The marketing surface uses locally served
Commissioner for readable editorial display lettering; the desktop's compact system
typography and design tokens remain unchanged.

STORY: An actual, original sample PDF leads into three photographed workspace
states. Download the same sample and try it in Folio. Everyday capabilities
lead into honest release/source boundaries and direct platform downloads.

FIRST VIEWPORT: A restrained masthead, a large ownership statement, a concise
PDF-workspace definition, a real platform download, and a wide real-app proof
surface. The screenshot is the artifact, not a generic split-hero illustration.

FORM: Code-led surface structure from seed `ad2eebbb`, assigned candidate 5
from the dealt set 5, 6, 1. The user was unavailable and requested autonomous
decisions. One real document, explored through reading, annotation and organization
views. A keyboard-operable proof selector changes the screenshot and caption,
not a simulated editor. Mobile shows a labeled crop of the desktop workspace,
not a fictional mobile application.

SIGNATURE INTERACTION: Explore a real workspace, download its original sample
PDF, and pass on the page through native sharing or an explicit copied link.
All downloads and contribution links are real destinations.

CONTENT TRUTH: Published v0.1.2 installers exist for Apple Silicon macOS, Windows
x64 and Linux x64, including the paragraph, tagged-copy, multilingual OCR and
offline trust feature wave. Future work on main may be ahead of this release;
label source-build screenshots accurately. No full Acrobat replacement,
PDF/UA certification, qualified/LTV assurance, fabricated ratings, users,
testimonials, signup urgency, analytics or document-upload service.

FINISH: Batch desktop and mobile review, keyboard/link/download checks, an
independent finish review, and asset provenance before publication through a PR.

## Website appearance extension

Default to System with live device following, plus persistent Light/Dark
overrides in the isolated `folio.site.appearance` key. The header uses an
accessible native selector, not a modal or decorative icon-only switch.
Dark surfaces inherit the desktop's graphite/slate and pale blue semantics;
the original blue source chapter and original PDF/screenshot pixels stay true.
Palette changes are atomic to retain contrast, including controls, selection,
focus, disclosure and sharing recovery. Storage failures remain explicit.

## Motion extension

FOCAL MOMENT: The actual document opens like Folio's folded-page mark: a bounded
740 ms sheet-corner mask and shallow perspective, paired with a 560 ms ownership
reveal. Content and download actions remain available; this is a photographed
workspace presentation, not invented PDF editing.

CONTINUITY: User-selected Read / Note / Organize views receive one 420 ms sheet
transition only after the selected real image loads, with matching captions.
Rapid input interrupts the old effect; no automatic preview carousel.

FEEDBACK: Download arrows move downward, source/link arrows move forward on
hover or keyboard focus. Hit targets and layout do not move.

BUDGET: Native Web Animations/CSS only, no loops, shaders, repeated scroll
reveals, libraries or raster changes. Reduced motion retains a brief crossfade
without sheet geometry; hidden pages, printing and preference changes cancel
effects. Bound transforms/masks to the headline and proof, with temporary hints.
